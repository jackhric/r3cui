How the custom UI reaches Kodi and the receiver

The Remote 3 core stays at the centre. Our program replaces only the on-screen app: it reads the keys, talks to the core, and the core's existing integrations do the talking to Kodi and Home Assistant.

Pressing volume up

  1. Volume key
  2. remote-ui
  3. remote-core
  4. Home Assistant integration
  5. Home Assistant
  6. Denon

The new level travels back the same way and the number on screen updates. If Home Assistant is down, this route stops.

Pressing the d-pad

  1. D-pad
  2. remote-ui
  3. remote-core
  4. Kodi integration
  5. Kodi

Title and playback position come back along this route, which is how the progress bar moves. It does not depend on Home Assistant.
